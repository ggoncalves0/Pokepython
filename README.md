# PokePython

> 🚧 **Projeto em desenvolvimento**: ainda está incompleto e muda com frequência.

Pokédex de desktop feita em **Python** com **Tkinter**. Ela mostra o nome, o tipo, o número, a imagem e os status de cada Pokémon numa interface gráfica simples.

## Funcionalidades

- [x] Janela principal com layout e paleta de cores
- [x] Exibição de nome, tipo e número do Pokémon
- [x] Imagem do Pokémon
- [x] Status (HP, Ataque, Defesa, Velocidade e Total)
- [ ] Botões para trocar de Pokémon
- [ ] Dados dinâmicos para cada Pokémon
- [ ] Habilidades

## Pokémon disponíveis (imagens)

Bulbasaur, Charmander, Pikachu, Gengar, Gyarados e Dragonite.

## Tecnologias

- [Python 3](https://www.python.org/)
- [Tkinter](https://docs.python.org/3/library/tkinter.html): interface gráfica (já vem com o Python)
- [Pillow](https://pypi.org/project/pillow/): carregamento e redimensionamento das imagens

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/Pokepython.git
   cd Pokepython
   ```

2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

3. Rode o programa:
   ```bash
   python main.py
   ```
